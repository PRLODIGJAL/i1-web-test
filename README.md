# 项目 i1 · 网站测试

两个 Three.js 3D 网页演示，用浏览器直接打开就能看，用来测试网页渲染和交互能力。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 世界名胜 · 交互式地球 —— 3D 地球 + 世界名胜标注，可拖拽旋转、滚轮缩放 |
| `dragon.html` | Dragon 3D 龙模型 —— 程序化生成的 3D 飞龙，拖拽旋转、滚轮缩放、右键平移 |
| `使用说明书.txt` | 使用文档 |

## 怎么打开

直接双击 `.html` 文件，浏览器自动打开。不需要装任何东西，不需要本地服务器。
需要联网（Three.js 从 CDN 加载）。

## 操作

- 鼠标左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移（dragon.html）
- ⏸ 按钮：暂停/恢复自动旋转（index.html）
